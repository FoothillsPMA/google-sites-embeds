How a process ends
✓ Support Ticket Resolved
⚡ Escalation Initiated
✕ Nuisance
Support Ticket Resolved — Call handled and fully documented. No further action needed.
Escalation Initiated — Issue required escalation per the Escalation Matrix.
Nuisance — Sales call, dropped call, or wrong number. Documented and canceled.

Nuisance Calls — Handle Nuisance

Canceled Stage
Objective: Handle nuisance or repeated non-actionable calls professionally while maintaining records for reference.
What counts as a nuisance call?
✓
Sales calls — unsolicited vendor or service outreach
✓
Dropped calls — call connected but no one responded
✓
Wrong numbers — caller intended to reach a different business
What to do
✓
Document the call details in a LeadSimple process note
{{process.on_call_notes}}
✓
If the caller exists in the system, note any recurring patterns or behavior in AppFolio
✓
Move the process to the Nuisance canceled stage
⚠️ Even nuisance calls must be documented. If a pattern develops with the same number or caller, that history in AppFolio becomes important.
